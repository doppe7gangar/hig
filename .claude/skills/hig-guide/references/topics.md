# HIG topics: where Apple says it

Every page of Apple's Human Interface Guidelines, 157 of them, with its official
address and the platforms it covers. This file holds no guidance of its own: read the
page on Apple's site for what it says, and quote it from there with the link. When the
concern isn't a component -- empty states, errors, onboarding -- `concepts.md` says which
page holds it.

Grep it: `grep -i sheet topics.md`.
